# ROOT archive — season one canon

## Public entry

The first record was not found in a database.

It was found in a maintenance printer that had been disconnected for seven years. One face. No name. A line through the eyes that stopped before reaching the edge.

Under it: `DO NOT RECONSTRUCT THE ADMINISTRATOR.`

By morning, two other sites had printed the same warning. The faces were different.

There were 1,111 records at each site.

The investigators called them GHOSTS. The records called the investigators witnesses.

## Three archive locations

**Cold storage:** an unpowered freight vault containing ceramic memory cassettes. **Relay well:** a retired long-distance switching shaft where faces emerge from conflicting signal paths. **Evidence void:** a forensic reconstruction environment that cannot locate its own source camera.

Shard assignment is a story index derived from token ID: `1 + ((id - 1) mod 3)`. Each shard has exactly 1,111 identities. It is not a scored rarity trait or an extra distribution allocation.

## Narrative rules

- The identities are persons within the fiction, not commodities inside it.
- ROOT is a network with conflicting responsibilities, not an omnipotent magic AI.
- No single narrator has the full event log. Contradiction is intentional; arbitrary retcon is not.
- Hidden clues contain authored fiction and synthetic data only. Never use real breached records or credentials.
- The three Genesis entities can be wrong without making the collector's immutable metadata false.
- The final revelation is consent: ROOT's greatest act was surrendering its authority to classify everyone.
